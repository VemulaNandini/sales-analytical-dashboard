This project focuses on analyzing sales transaction data across EMEA regions using Python. 
The goal is to extract insights about top-performing locations, year-over-year (YoY) trends, and overall sales distribution. 
The project replaces Power BI with Python-based visualizations to keep it lightweight and accessible.

Files in the Repository
•	EDA_sales_analysis.ipynb – Jupyter Notebook containing the full end-to-end analysis.
•	top_locations.csv – CSV file of top 10 revenue-generating locations.
•	yoy_growth.csv – CSV file showing year-over-year transaction growth.

Key Insights
•	Identified top 10 high-performing sales regions by transaction amount.
•	Calculated YoY transaction growth trends.
•	Used pandas, matplotlib, seaborn, and numpy for data exploration and visualization.

Dataset Information 
•	The dataset used for this analysis is bank_transactions.csv, sourced from Kaggle.
•	Due to GitHub file size limitations, the dataset is not included in the repository.
•	Download the dataset from Kaggle by searching for bank_transactions.

Tools & Skills Used
•	Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
•	Data Cleaning, EDA, CSV Output, Visual Analytics
